# skills/

Mỗi skill là một thư mục chứa `SKILL.md` mô tả **quy trình nhiều bước lặp lại** trong dự án.
Frontmatter: `name`, `description` (khi nào dùng). Thân: các bước + file liên quan + cách kiểm chứng.

| Skill | Dùng khi |
|---|---|
| `add-unit-card/` | Thêm/sửa Unit card hoặc ability dùng trigger/effect có sẵn |
| `add-match-command/` | Thêm một thao tác người chơi mới đi qua client → server → Domain → snapshot |
| `adjust-shop-economy/` | Đổi giá/tier/starter, thêm thẻ vào Shop, đổi mức thưởng — đồng bộ code, asset và Firestore Rules |

(Đang soạn — bổ sung khi có quy trình mới lặp lại ≥ 2 lần.)
