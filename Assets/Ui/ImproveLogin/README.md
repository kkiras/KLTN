# ImproveLoginScene

Current project layout: the redesigned scene has been renamed to
`Assets/Scenes/LoginScene.unity`; the original is `Assets/Scenes/OldLoginScene.unity`.
The form is now 564 units wide (660 → 610 → 564), input/button rows are 460 units wide
(556 → 506 → 460), and all form text is 6 units smaller in total at the reference resolution.
Icon sizes, frame height and border thickness are unchanged. These adjustments were
made directly in the scene file without opening or controlling Unity.

Primary action buttons and Google sign-in are now 64 units high (previously 82).
The recovery back link uses the supplied `Sprites/back-arrow.png` as a separate,
non-raycastable cream/coral-tinted icon; only its text is underlined. The image's
original pixels are retained and tinted using the existing AlphaTint material.

Open `Assets/Scenes/ImproveLoginScene.unity` in Unity to preview this isolated redesign.
The original `LoginScene`, shared authentication scripts, original notification prefab,
Build Profiles and default login/logout routing are unchanged. This scene is an editable
clone, not a runtime-generated UI. Promotion to the default login scene is a separate step.

The three panels share one frame: email/password login, registration with confirmation,
and email-based password recovery. `ImprovedAuthNavigation` delegates authentication and
busy state to the existing `LoginUI`, `RegisterUI`, `GoogleLoginUI` and `AuthUIManager`.
Password visibility resets when its panel is disabled. Tab/Shift+Tab cycles visible
controls; Enter submits the existing password/confirmation inputs and the recovery input.

The design uses a 1920 x 1080 reference surface and CanvasScaler Expand. Other aspect
ratios retain the composition with a dark surrounding background. Screenshots are in
`Logs/ImproveLogin/` after editor validation.

The current form palette is muted coral red `#D96862`, with `#E57B73` text accents.
The frame uses its own `Sprites/panel-outline.png`: 4 px straight-edge coverage at
the reference scale, 2 px thicker than the original outline. Input borders are unchanged.
These latest visual edits were checked in the serialized files, without opening or
controlling Unity; existing screenshots predate this palette update.

## Validation

`Tools/KLTN/Validate ImproveLoginScene` checks panel navigation, operation locking,
password visibility, serialized references and audio controls, and renders previews
at 1920 x 1080, 1366 x 768 and 1920 x 1200. It does not contact authentication services.

Batch entry point `KLTN.Game.Editor.ImproveLoginRuntimeValidation.Run` runs an offline
Play Mode smoke check: scene lifecycle, button raycasts, invalid-input feedback, recovery
email handoff, busy lock/recovery and password remasking. Run it in a separate batch
Unity process without `-quit`; it exits with a test status. Service roots are disabled
only in that unsaved test session. Actual Google login and successful server requests
require testing with an account in the normal scene.

`Tools/KLTN/Build ImproveLoginScene` is the one-time construction tool and refuses to
overwrite an existing ImproveLoginScene. Edit the delivered scene directly for further
layout changes; no regeneration is required.
